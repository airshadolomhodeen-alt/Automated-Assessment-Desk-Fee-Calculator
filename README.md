# Philippine Building Permit Fee Calculator (NBCDO MC No. 03 / Revised IRR of PD 1096)

A complete, production-ready, modular Streamlit web application that accurately computes building permit fees, accessory fees, electrical, mechanical, plumbing, electronics fees, certificate costs, and annual inspection fees in strict accordance with NBCDO Memorandum Circular No. 03 (Series of 2016).

## Features
- **Comprehensive Modules**: Covers Building, Electrical, Mechanical, Plumbing, Electronics, Accessories, Other Fees, and Certificates/Inspection Fees.
- **Cumulative Calculation Logic**: Implements precise bracket-based cumulative calculations for large floor areas (Divisions B, C, D, E, F, G, H, I, J).
- **Live Summary & CSV Export**: Real-time aggregation of fees into a Grand Total with one-click report download.
